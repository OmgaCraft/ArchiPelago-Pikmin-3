# Pikmin 3 Beta

## What is this?

A **beta** of the Pikmin 3 Archipelago integration, separate from the planned final version ("Pikmin 3"). It adds
checks and items whose memory data is not fully verified yet, and a **discovery journal** in the client that records
every change in the watched game memory, to find new items and checks while playing.

## Where is the options page?

The [player options page for this game](../player-options) contains all the options you need to configure and export
a config file.

## What does randomization do to this game?

Every fruit you juice sends a check. Fruits no longer give juice: your juice arrives as items named after the fruits
of Pikmin 3. Other checks: Onions discovered, key items and upgrades, Pikmin population milestones, and in this beta
days reached, new fruit kinds, GamePad notes (four sets counted separately) and story events.

Items: fruit juice, Progressive Pikmin Limit, extra Pikmin of every colour, Ultra-Spicy Sprays and Berries, and an
optional juice leak trap.

## What is the goal?

Juice a given number of fruits, or reach a given Pikmin population.

## Which version of the game is supported?

Version 1 (disc, no update) of **Pikmin 3 (Europe)** on Wii U, running on **Cemu** 2.6 or newer on Windows.
